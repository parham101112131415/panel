# Parham Theme

تم قرمز/مشکی Parham برای پنل و صفحه سابسکریپشن + حذف تبلیغات/حمایت.

## چی داخلشه

**داشبورد ادمین** (`dashboard-overlay/` mirror of `dashboard/`):
- تم `parham` (قرمز/مشکی) + پیش‌فرض dark — از صفحه Theme قابل برگشت به تم‌های قبلی
- حذف کامل: پاپ‌آپ Donate، نوار Goal، تبلیغ بالای صفحه (TopbarAd)، دکمه Star گیت‌هاب، آیتم Support Us، لینک گروه تلگرام
- فوتر: `Made with 🔥 by Parham` + اسم پنل همه‌جا Parham
- افکت‌ها: بک‌گراند گرادیان متحرک، حباب‌ها، صداهای واقعی (Kenney CC0)، ریپل + جرقه روی کلیک (فقط تپ واقعی، نه اسکرول)، صدای toggle/open/close/success/error، دکمه mute، انیمیشن مودال و شورون آکاردئون
- لوگوی P قرمز/مشکی (جایگزین favicon)

**صفحه سابسکریپشن** (`subtpl-overlay/`):
- حذف بلوک لینک پشتیبانی، فوتر Parham
- همون تم قرمز/مشکی + افکت‌ها (صداها داخل خود فایل embed شدن چون خروجی تک‌فایل است)

## Version pins (مهم)

| چیز | مقدار | کجا عوض میشه |
|---|---|---|
| سورس داشبورد + ایمیج بیس | `v5.4.1` | `UPSTREAM_TAG` و `FROM pasarguard/panel:v5.4.1` |
| سورس سابسکریپشن | `ba2d786` (v2.2.1) | `SUBTPL_REF` |

هر سه رو **با هم** بالا ببر، وگرنه overlay با سورس نمی‌خونه و بیلد می‌شکنه.

## Build args لازم (Railway)

| arg | چی بذار |
|---|---|
| `VITE_PANEL_DOMAIN` | **دامنه واقعی پنلت** (داخل JS سابسکریپشن bake میشه؛ با example.com کار نمی‌کنه!) |

بقیه argها پیش‌فرض قرمز دارن.

## نکته لایسنس

سورس upstream تحت AGPL-3.0 هست — چون ریپو پابلیکه و overlay داخلشه، مشکلی نیست. فایل‌های صوتی CC0 (Kenney) با لایسنس‌شون داخل `dashboard-overlay/public/statics/sfx/` هست.

## Node

ریپوی Node سرویس Go بدون هیچ UI هست — چیزی برای تم نداره، دست نخورده.
